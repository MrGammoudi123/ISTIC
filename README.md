# AcademiQ — ISTIC Rattrapage Dashboard

A interactive web dashboard for ISTIC students to simulate and track their **rattrapage (makeup exam)** grades for Semester 1.

## Live Demo

**[https://mrgammoudi123.github.io/ISTIC/](https://mrgammoudi123.github.io/ISTIC/)**

## Features

- **ISTIC Landing Page** — Semester selector with SEM 1 (active) and SEM 2 (coming soon)
- **Grade Simulator** — Drag sliders to project your final average in real time
- **Smart Prediction** — Best / Realistic / Worst case scenarios with pass probability
- **Goal Simulator** — Set a target grade and see the exact average needed across subjects
- **Required Grades Table** — See what you need per subject to hit 9/20 through 14/20
- **Performance Charts** — Radar chart and bar chart (Notes vs Crédits)
- **Editable Fixed Grades** — Unlock and adjust grades for non-retake subjects
- **Dark / Light theme** + 4 accent colors
- **Export screenshot** of the full dashboard

## Keyboard Shortcuts

| Key | Action |
|---|---|
| `T` | Toggle dark / light theme |
| `R` | Reset all grades |
| `E` | Export screenshot |
| `1–4` | Switch accent color |

## Tech Stack

- Pure HTML / CSS / JavaScript — no build tools, no frameworks
- [Chart.js](https://www.chartjs.org/) for radar and bar charts
- [html2canvas](https://html2canvas.hertzen.com/) for screenshot export
